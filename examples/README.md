# Examples

The first two prototypes, kept as short single-file starting points. The full app in `emotion_recognition/` grew out of them.

| File | What it shows |
|---|---|
| `01_face_detection.py` | Real-time face detection with an OpenCV Haar cascade and a face counter. OpenCV only. |
| `02_emotion_single_label.py` | One DeepFace emotion label for the whole frame, with an FPS counter and screenshots (`S`). |

Run from the repository root, for example `python examples/01_face_detection.py`. Press `Q` to quit.
